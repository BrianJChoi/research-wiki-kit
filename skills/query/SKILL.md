# query (연구 볼트용)

## 공용 경로

먼저 이 스킬 파일에서 상대 경로 `../../references/vault-layout.md`를 읽고, 대상 볼트의 `CLAUDE.md`와 함께 적용합니다. 아래 경로 예시는 공용 표의 역할을 뜻하며 사용자 규칙이 우선합니다.

위키가 첫 번째 출처이고, 원문은 마지막에 봅니다.

## 절차

1. **INDEX 먼저:** `CLAUDE.md`의 위키 운영 규칙에 적힌 `INDEX.md`를 읽고 질문과 관련된 페이지를 고릅니다.
2. 관련 개념 페이지와 논문 노트(`Literature/`)를 읽고 종합합니다. 서로 다른 말을 하면 둘 다 인용합니다.
3. 위키로 부족할 때만 원문 폴더나 Zotero를 봅니다. 거기서 답을 찾았다면 위키에 빠진 부분이 있다는 뜻이므로 ingest를 제안합니다.
4. 답합니다. 핵심 주장마다 출처를 답니다: `출처: [[노트 이름]]`, 논문은 `[[Literature/@인용키]]`와 쪽.
5. 저자의 말, 내 노트의 말, AI의 해석을 구분합니다. 해석에는 "해석:"을 붙입니다.
6. 답이 새로운 연결이나 종합이라 남길 가치가 있으면 위키에 저장할지 묻습니다. 저장하면 INDEX를 갱신하고 `log.md`에 `- [YYYY-MM-DD] query | 질문 요약`을 적습니다.

## 지킬 것

- 위키에 없는 내용은 지어내지 않습니다. "위키에 아직 없습니다. ○○를 ingest할까요?"라고 답합니다.
- 일반 지식으로 답할 때는 위키 근거가 아니라고 밝힙니다.
