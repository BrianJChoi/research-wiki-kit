# ingest (연구 볼트용)

## 공용 경로

먼저 이 스킬 파일에서 상대 경로 `../../references/vault-layout.md`를 읽고, 대상 볼트의 `CLAUDE.md`와 함께 적용합니다. 아래 경로 예시는 공용 표의 역할을 뜻하며 사용자 규칙이 우선합니다.

자료 하나를 넣으면 개념 페이지, INDEX, log까지 한 번에 처리합니다.

## 입력

- 논문 노트 `Literature/@인용키.md` (논문 노트 스킬로 만든 것)
- 원문 폴더의 파일 (웹 클리핑, 강의 자료)

폴더 이름은 `CLAUDE.md`의 위키 운영 규칙을 따릅니다. 규칙이 없으면 `wiki-setup`을 먼저 하자고 제안합니다.

## 사용량 원칙

- 한 번에 자료 1편씩 처리합니다.
- 논문은 논문 노트(하이라이트, 코멘트, 초록)를 먼저 씁니다. 본문이 꼭 필요할 때만 `zotero_get_item_fulltext`로 읽고, 그 전에 사용자에게 사용량이 크다고 알립니다.

## 1단계: 자료 이해

1. 자료를 읽습니다. **원문 폴더의 파일은 고치지 않습니다.**
2. 짧은 요약을 보여 줍니다. 핵심 내용 3줄과 다루는 개념 목록입니다.
3. 사용자가 남기고 싶은 점을 말했으면 반영하고 바로 진행합니다. 입력 범위가 불분명할 때만 확인합니다.

## 2단계: 위키에 반영

1. `INDEX.md`를 먼저 봅니다. 같은 개념 페이지가 있으면 새로 만들지 않고 보강합니다.
2. 원문·초록·하이라이트를 실제로 확인합니다. AI 요약이나 기존 위키만으로 재생성하지 않습니다. 원문이 없으면 그 한계를 표시합니다. 시간이 지나도 맞는 지식만 뽑아 개념 페이지를 만들거나 보강합니다.
3. 개념 페이지에는 아래를 넣습니다.
   - YAML 속성: `type: concept`, `title`, `description`, `tags`, `sources`, `updated`
   - 정의, 주요 주장, 근거, 한계
   - 저자의 말과 AI의 해석을 구분합니다. 해석에는 "해석:"을 붙입니다.
   - 출처: `[[Literature/@인용키]]`와 쪽, 웹 글은 `[[원문 파일 이름]]`
   - 관련 개념: `[[다른 개념]]`
4. 출처끼리 다른 말을 하면 둘 다 적습니다.
5. `INDEX.md`에 한 줄(120자 이내)로 더하거나 고칩니다.
6. `log.md`에 기록합니다: `- [YYYY-MM-DD] ingest | 자료 이름 → [[만든 페이지]], [[보강한 페이지]]`

## 3단계: 보고

만들거나 보강한 페이지, 기존 페이지와 이어진 개념을 알려 줍니다. 그래프 뷰에서 확인해 보라고 안내합니다.

## 지킬 것

- 자료에 없는 내용을 지어내지 않습니다.
- 판단이 애매한 내용은 "확인 필요"로 표시합니다.
- 자동으로 뽑은 개념은 정독을 대신하지 않습니다. 중요한 논문은 직접 읽고 "내 생각"을 쓰도록 안내합니다.
