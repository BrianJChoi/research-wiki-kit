# 아웃라인에서 원고로

## 공용 경로

먼저 이 스킬 파일에서 상대 경로 `../../references/vault-layout.md`를 읽고, 대상 볼트의 `CLAUDE.md`와 함께 적용합니다. 아래 경로 예시는 공용 표의 역할을 뜻하며 사용자 규칙이 우선합니다.

강사의 노트망→논문 워크플로를 Markdown용으로 고쳤습니다.

## 입력과 근거

1. 사용자가 직접 쓴 아웃라인을 읽습니다. 없으면 연구 질문과 절별 주장부터 적도록 안내합니다. 빈 원고를 임의로 완성하지 않습니다.
2. `[[경로/노트#절|별칭]]`을 따라 1단계 연결 노트를 읽습니다. 사용자가 요청한 경우에만 2단계까지 넓힙니다. 한글 파일은 NFC/NFD를 정규화해 비교합니다. 동명이인 파일이나 깨진 링크는 임의로 고르지 않고 표시합니다.
3. 노트→원고 절→근거 출처의 소스 맵을 짧게 보여 줍니다. 사용자가 이미 아웃라인을 확정했다면 그대로 작성합니다. 구조 변경이 필요할 때만 제안합니다.
4. 문헌의 실제 근거는 Zotero 읽기 도구로 확인합니다. 메타데이터와 BibTeX에서 Better BibTeX 키를 확인하며 없는 키를 만들지 않습니다. 초록만 읽었으면 초록 기준이라고 표시합니다.

## 양식과 언어

사용자가 정한 형식·한국어/영어를 따릅니다. 미지정이면 한국어 리서치 프로포절을 기본으로 쓰고 시작할 때 알립니다. 아웃라인에 있는 절의 순서와 연구자의 주장을 보존합니다.

| 양식 | 절 구성 |
|---|---|
| 한국 학술지 일반형 | 국문초록·주제어, 서론, 이론적 배경, 연구방법, 연구결과, 결론, 참고문헌, 영문초록 |
| 영문 IMRaD | Abstract·Keywords, Introduction, Methods, Results, Discussion, Conclusion, References |
| 리서치 프로포절 | 배경, 연구 질문, 선행연구, 방법, 기대효과, 참고문헌 |

일반형은 특정 학술지의 공식 투고 양식이 아닙니다. 실제 학술지 규정은 연구자가 제공합니다.

## 작성·저장

- 공용 표의 연구 폴더 또는 지정 프로젝트에 `<주제>-draft.md`를 만듭니다. 기존 원고가 있으면 읽고, 요청한 변경만 반영하거나 새 파일명을 정합니다.
- YAML에 title, created, lang (`ko-KR` 또는 `en-US`), manuscript_format (`korean`, `imrad`, `proposal`)을 기록합니다.
- 각 절에 `근거: [[볼트 기준 노트 경로]]`를 남깁니다. 인용은 `[@실제키]`를 기본으로 하고 `[[@실제키]]`도 허용합니다. 쪽 근거를 알면 `[@실제키, p. 5]`로 적습니다.
- 연구자가 쓴 주장과 해석을 보존합니다. 없는 실험·표본·통계·연구결과를 만들지 않습니다. 빈 절과 근거 없는 문장은 `TODO: 근거 필요 — …`로 표시합니다. 결과가 없는 프로포절은 예상 결과를 실측 결과처럼 쓰지 않습니다.
- 사용자의 내 생각을 대신 작성하지 않습니다. 참고문헌의 원본 서지는 Zotero에서 확인합니다.
- 루트 `references.bib`가 자동 갱신 중이면 손으로 수정하지 않습니다. 빠진 키는 보고하고 Better BibTeX 내보내기를 갱신하도록 안내합니다. 필요하면 확인한 서지만 프로젝트 별도 bib으로 제안합니다.
- 완료 시 원고 경로, 소스 맵, 확인한 키, 깨진 링크·미근거 TODO를 보고하고 cite-check를 안내합니다. Word는 manuscript-export로 이어집니다. LaTeX는 이 스킬의 기본 출력에 포함하지 않습니다.
