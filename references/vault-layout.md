# 연구 볼트의 공용 폴더 규칙

모든 키트 스킬은 작업 전에 이 파일과 대상 볼트의 `CLAUDE.md`를 읽습니다.
사용자가 지정한 위치와 볼트의 명시적 규칙을 우선합니다. 아래는 수업용 기본안이며 아직 최종 구조가 아닙니다. 기존 볼트를 자동 이동하거나 이름을 바꾸지 않습니다.
스킬 파일 기준 `../../references/vault-layout.md`입니다. 설치 위치를 추측하지 말고 실행 중인 스킬 파일의 실제 경로에서 찾습니다.

| 역할 | 기본 경로 | 내용 |
|---|---|---|
| 원문 | `Raw/` | 원본 웹 글·자료. 수정하지 않습니다 |
| 위키 | `Wiki/` | 개념 페이지, `INDEX.md`, `log.md` |
| 논문 노트 | `Literature/` | `@citekey.md`, 서지·하이라이트·코멘트 |
| 토픽 | `Topic/` | 여러 논문을 연결하는 주제 노트 |
| 연구 | `Research/` | 조사·관점 탐색·프로젝트·원고·내보내기 |
| 데일리 | `Daily/` | 날짜별 기록 |
| 템플릿 | `Templates/` | 논문·토픽·데일리 템플릿 |
| 서지 | `references.bib` | 볼트 루트, Better BibTeX 자동 내보내기 |

문서의 경로 예시는 위 역할로 해석합니다. 기본 폴더 이름을 바꿀 때는 이 표 한 곳을 고칩니다.
`wiki-setup`은 확정된 사용자 지시가 있으면 그 범위에서 생성하고, 구조 선택이 필요한 경우에만 제안 후 확인받습니다.
모든 쓰기 전에 기존 파일을 읽습니다. 사용자 문장·내 생각·원문은 보존합니다. 같은 개념은 새 페이지보다 보강을 우선합니다.
날짜는 사용자의 현지 시간대를 따르며 수업 기본은 Asia/Seoul입니다.
위키 링크는 볼트 기준 경로와 필요하면 별칭을 사용합니다. 한글 이름은 NFC/NFD를 정규화해 찾고, 이름이 같으면 경로를 확인합니다.
