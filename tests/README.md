# v0.3.0 시험

Python 3.10 이상과 Pandoc이 있으면 저장소 루트에서 실행합니다. uv를 쓰는 경우:

```text
uv run --python 3.12 python -m unittest discover -s tests -v
```

합성 서지와 임시 볼트를 사용합니다. Zotero에 쓰지 않고, 키나 네트워크 없이 동작합니다. 세 양식의 인용·링크·콜아웃, 미해결 키, 원본 보존과 업데이트의 백업·롤백·압축 경로·릴리스 선택을 확인합니다.

이는 Claude가 스킬을 선택하고 판단하는 실습이나 Windows·Word 실기 시험을 대신하지 않습니다. 테스트는 Mac과 Windows에서 실행할 수 있으나 실제 실행한 플랫폼만 시험 기록에 적습니다. 기존 zotero-add-paper 회귀 시험은 별도 개발 브랜치에서 관리하며 이 릴리스가 그 미병합 변경을 포함하지 않습니다.
